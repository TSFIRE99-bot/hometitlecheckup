# Founder checklist

Things only the founders (or an adult acting for them) can do. Nothing here has been done yet.

## This week

- [ ] Sign in to Vercel in the browser and open the `homekeep-pro` preview. Click through `/pro`, the demo, a family
      link and a packet export. Note anything confusing.
- [ ] Read `CLAIMS_AUDIT.md` and the corrected public wording on the preview (home page, Learn, About, inheritance
      calculator) in all three languages.
- [ ] Decide whether `/pro` should exist on the live site yet. Until then, don't merge `homekeep-pro` into `main`.
- [ ] Read `SALES_KIT.md` and `prospects.csv`. Approve, edit or cut each draft and the top 10 firms.
- [ ] Decide who sends outreach and from which email address.

## Before the first conversation

- [ ] Agree on how you'll describe yourselves: students, not a law firm, no certifications.
- [ ] Set up the shared tracker (import `prospects.csv` into Google Sheets).
- [ ] Practice the 90-second demo with each other twice.

## Before the first pilot

- [ ] Find an Ohio attorney (a parent's contact, a law school clinic, or a legal aid adviser) to review
      `DRAFT_TERMS.md`, the security page and the pilot offer.
- [ ] Decide who the contracting party is, given that some founders are under 18.
- [ ] Set up a durable database and `SECRET_KEY` (see `SETUP.md`). Budget: write down the monthly cost.
- [ ] Decide on malware scanning for uploads.
- [ ] Decide whether to buy insurance; get a quote.
- [ ] Set up payments in test mode only, through a processor an adult signs up for. Don't collect a real payment until
      the pilot agreement is reviewed and signed.

## During each pilot

- [ ] Get the firm's baseline (last three matters) before day 1.
- [ ] Check the Pilot measures panel weekly and log support time.
- [ ] Write the end-of-pilot report honestly, including what didn't work.
