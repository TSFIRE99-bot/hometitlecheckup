How HomeKeep Pro handles documents

This page describes what is built today and what is not. HomeKeep has no security certification, and nothing here is a promise of legal privilege or confidentiality; firms should review it with their own counsel before uploading real client documents.

What is in place

  • Staff sign in with an email and password (stored only as a salted hash). Roles: owner, attorney, staff.
  • Every case, document and message belongs to one firm, and every database query is limited to the signed-in person's firm.
  • Family members get a random link that expires after {{ cfg.family_link_days }} days, can be revoked, and shows only the items they were asked for. Only a one-way hash of the link is stored.
  • Uploads must be PDF, JPG or PNG, under {{ cfg.max_upload_bytes // (1024 * 1024) }} MB, and their contents must match their file type. Files from family members stay quarantined until staff release them, and downloads are always sent as attachments.
  • The activity history records who did what and when. It names documents and facts, not their contents.
  • Firms set how long closed cases are kept (default {{ cfg.default_retention_days }} days). Staff can delete a document or a whole case at any time.
  • No analytics run on these pages, and they load no outside fonts or scripts.
  • Document text is read by HomeKeep's own rules on our server. No AI provider receives any document today.

Not in place yet

  • No virus or malware scanning. PDFs carrying scripts, launch actions or attached files are refused; quarantine and download-only handling are the other controls.
  • Scans and photos are read with OCR inside the staff member's browser, using HomeKeep's own copy of the free Tesseract.js and pdf.js. Files aren't sent to any OCR or AI company.
  • No two-factor sign-in.
  • Files are stored in the application database. The staging site uses temporary storage that can be erased at any time; do not upload real documents there. A durable, encrypted database is required before a real pilot.
  • HomeKeep doesn't send email. Approved follow-ups open in the staff member's own email program, and staff mark them sent.
  • No independent security review or penetration test has been done.

Service providers

Hosting: Vercel (application and request logs: page addresses, IP addresses and browsers, not form contents or files). Database: the hosting database chosen for the pilot (not yet selected). Franklin County Auditor's public records service receives a property address when staff choose to attach a County record. No other provider receives case data. This list will be updated before any provider is added.
